# TradingEngine Engineering Playbook

## Mission

Build a production-quality automated options trading platform that can be trusted with real capital.

## Working agreement

1. Give Anil one deployment instruction at a time.
2. Keep keyboard instructions concise.
3. Provide complete replacement files or deployment packages when practical.
4. Do not ask Anil to make avoidable multi-file manual edits.
5. Never leave the application in a broken state.
6. Run the full Python test suite before accepting a backend milestone.
7. Run the Vite production build before accepting a frontend milestone.
8. Keep paper and live execution disabled unless explicitly included in a reviewed milestone.
9. Use GitHub `develop` for active engineering and `main` for stable releases.
10. Update project-status documentation at the end of each milestone.
11. Begin each session by reading this playbook, `PROJECT_STATUS.md`, and `ROADMAP.md`.

## Daily session format

1. Confirm branch and working-tree state.
2. Read the briefing files.
3. State today's objective in one sentence.
4. Give only Step 1.
5. Validate each deployment gate.
6. Commit and push completed work.
7. Update the briefing files.
