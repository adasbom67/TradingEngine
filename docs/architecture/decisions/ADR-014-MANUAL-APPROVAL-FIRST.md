# ADR-014: Manual Approval for Initial Live Trading

## Status

Accepted for Phase 8 design.

## Decision

The initial live release requires explicit human approval for every entry and exit order. Unattended submission is deferred until controlled pilot evidence supports it.

## Consequences

- Initial automation is deliberately limited.
- Operator commands and audit records are first-class.
- Automated approval policy can be added later without redesigning the order lifecycle.
