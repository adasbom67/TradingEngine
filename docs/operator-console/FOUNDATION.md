# Operator Console Foundation

## Scope
- FastAPI read-only application boundary
- React/TypeScript application shell
- Option C hybrid navigation
- Apple Pro-inspired visual language
- responsive desktop, tablet, and phone layouts
- Trading Day command-center dashboard
- health and version integration

## Safety
The foundation exposes GET-only endpoints. It contains no broker order submission, cancellation, replacement, or account mutation routes.

## Run
1. `pip install -r requirements-operator-console.txt`
2. `python operator_api.py`
3. In another terminal: `cd operator-console`
4. `npm install`
5. `npm run dev`
6. Open `http://127.0.0.1:5173`
