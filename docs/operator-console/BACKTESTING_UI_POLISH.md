# Backtesting UI Polish v0.2.1

Included:
- $100,000 default capital with thousands separators
- $25K, $50K, $100K, $250K, and $500K presets
- progressive run-status messages
- larger summary cards
- positive and negative P/L styling
- hover and sticky-header improvements for recent trades
- responsive capital controls

Historical Delta, score, decision, and exact option expiration are not added to
the backtest table because the current historical backtest model does not
produce those values. They will be added only when supported by the research
engine.
